# 暂借中间值，再从正式初值重建

同一道题分别从三种起点搜索。第一种直接改进原程序；第二种暂时把原程序中多处使用的数放进初始寄存器；第三种借用原程序未使用、但可能帮助生成多个旧值的数。搜索结束后，必须从官方初值重新构造用到的每个借值，并在真实寄存器上重放所有目标。三组使用相同种子和轮数，独立与公开辅助程序分别比较。[固定范围、预算与扩展条件](design.json)

按 [构建脚本](../reactive-tabu/build.py) 编译 original 引擎后，在仓库根目录运行以下命令。将 `own` 换为 `public` 可复跑公开辅助组，将 `development` 换为 `holdout` 可复跑留出题。

```shell
python -B collaboration/borrowed-starts/compare.py --phase development --lane own --puzzles data/puzzles.csv --exe work/bin/original --out work/borrowed --jobs 4
```

12 道开发题在两条路线均未缩短。在各 24 道留出题里，独立路线在两道题共省 2 条，第 39 题的借值方案比直接搜索多省 1 条。公开辅助组没有缩短，本轮结束。独立路线的 804 道扩展题已完成。开发、留出和扩展合计 840 道，按题择短后有 148 道共省 198 条。相同预算的直接搜索省 55 条。108 道题用借值方法得到比直接搜索更短的程序。[各批统计与缩短程序](results/summary.json)

归档的每个压缩文件含三种方法的逐题结果、所用初值以及所有缩短的程序。将相应文件放到临时目录并以该目录作为 `--out`，加 `--replay-only` 可以重放整张提交。扩展题用 `--phase expand --block 0` 起按批复核。

## 同时暂借由同一中间数产生的一组值

从双方程序只差 0 到 3 条的题中选出 40 道，其中 20 道曾在此前的借值搜索中缩短，另选 20 道作对照。对当前公开和独立程序分别测试直接搜索、单层借值和共享一层新前缀的借值；同一份程序只搜索一次。每组两段各 400 轮，使用相同的新随机种子。全部前缀及恢复步骤计入最终得分。[题号与父本](shared-prefix-design.json) · [搜索程序](shared_prefix.py)

40 道题已完成。直接搜索、单层借值、共享前缀在独立父本上分别省 1、3、3 条，按题取最短共省 4 条。第 871 题仅共享前缀有改进，112→111。公开辅助组均未缩短。[逐题结果](shared-prefix-results.json.gz)

## 借用旧解中消失的中间数

从五个历史版本与当前独立解中挑选曾被反复使用、已从现有程序消失的中间数。在 16 道开发题和 32 道留出题上比较直接搜索、借新数和借旧数，全部按最终可执行程序的实际长度计分。[题号与历史版本](historical-design.json) · [搜索程序](historical_values.py)

两组共 48 道题，三种方法均未省下指令，结束此方向。[逐题记录](historical-results.json.gz)
