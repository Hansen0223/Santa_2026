# 132,544 条候选的还原方式

在仓库根目录运行以下命令。先将官方比赛 ZIP 中的 `puzzles.csv` 放入 `data/`，再下载 Asterios Panoras 发布的第 182 版原始 ZIP，保留压缩包。[Asterios v182](https://www.kaggle.com/datasets/asteriospanoras/santa-2026-elf-programs-and-experiments/versions/182)

```sh
python -B public-assisted/releases/asterios_v182.py --puzzles data/puzzles.csv --archive asteriospanoras-182.zip --out combined
```

输出 `combined/submission.csv` 和 `combined/result.json`。完整提交含 1,000 题和 132,544 条指令，SHA-256 为 `2ae6182bd428c3562bed7d708dd4e7a53e6047b7a982f9e1483ab28f004b4f44`。程序固定读取 Git 提交 `ae39b66` 中的两份解，检查原始压缩包哈希并重放所有入选程序。[逐题差额与输入指纹](v182-assembly.json)

Asterios 汇总的原版为 132,647 条，作者标注 Apache 2.0，各上游输入保留原署名和条款。仓库的 Hiyohane、WorkBuddy 和其他协作者提供了可继续缩短整份解的程序。对比原版，16 题共省 103 条。最终有 551 题选自 Asterios，375 题取自仓库的公开辅助解，73 题取自独立解，1 题使用本轮搜索结果。等长时优先采用仓库的独立程序，其次采用仓库的公开辅助程序。[独立路线逐题署名](../../origins.csv) · [公开辅助路线逐题署名](../origins.csv)

本轮在 986 题上用两种方法比较新旧程序。第 756 题从 151 条减到 150 条。方法来自 Wang Jakie 和 E-Max AI 发布的算术图搜索；两组规模、固定种子、输入顺序及逐题结果随实验归档。[第 756 题的新程序](v182-search-wins.csv) · [实验记录](v182-search-results.json.gz) · [E-Max AI 搜索源码](https://www.kaggle.com/datasets/royalacecat/santa-2026-retained-graph-search-source/versions/7)
