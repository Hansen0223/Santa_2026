# 扩展最优性证明 · proofs_ext

本目录是 `proofs/` 的**增量扩展层**：原有证明、判定回执与表格一律不改写。
新判定追加到 [decisions.json](decisions.json)，合并后的逐题上下界见
[bounds.csv](bounds.csv)（上界采用独立改进提交 `improve/submission.csv`，136,991 条）。

领取新题时可先查看全仓库已证下界和已登记的搜索。运行 `python -B collaboration/next_proofs.py --puzzles data/puzzles.csv` 会列出仍能提高项目总下界的题号与辅助数预算，自动跳过已登记的同题同预算任务。[逐题汇总](../collaboration/puzzle-bounds.csv) · [当前分工](../collaboration/STATUS.md)

## 方法

与原证明相同的松弛模型：所有已产生的数永久可用，任何 48 寄存器程序都可被模拟。
对给定辅助数预算做分片穷举，全部分片返回 `UNSAT` 才记下界
`缺失目标数 + 预算 + 1`；达到节点上限的 `UNKNOWN` 一律不记录。
每道题先用 `--audit-pairs` 核对双输出剪枝。搜索与复核共用 `work/proofs/audit-cache/` 下的本机结果，以题目输入和实际执行文件的 SHA-256 区分版本。换编译版本、换题目输入或指定 `--refresh-audit` 时会重新运行。贡献者的原始记录见 `audit.d/`。

## 与协作会话的关系 · 只追严格增益

另一会话（Hansen0223/Codex）在 `collaboration/` 维护更强的逐题认证下界
（`puzzle-bounds.csv`，总下界 37,980，20 题已紧；其 helper-wave 与
diamond/conditioned 回放认证已吸收本层早期
31 项严格增益，双方独立互证）。本层早期的预算 4/5/6 增量判定
全部被其覆盖，不再产生严格价值。因此 `batch_lower.py` 已改为**只搜索能严格超过
已发布下界的预算**：对每题取 `floor = max(协作 certified_lower, 本层 certified_lower)`，
搜索最小预算 `b = floor − 缺失目标数`，全 UNSAT 即得 `缺失 + b + 1 > floor` 的严格增益。
协作会话保留的深搜网格（0882 h10、0901 h10、0149 h10、0212 h11）一律跳过，避免重复。
节点上限内无法判定的难题快速跳过，先收割廉价严格增益，再对 promising 题提高上限复核。
